## 2. Единицы и системы координат

- Все величины в **СИ**: метры, килограммы, секунды, радианы.
- Модель дрона: **X — вперёд, Y — влево, Z — вверх** (как в Gazebo и ROS).
- Мир: **ENU** (X — восток, Y — север, Z — вверх).
- Автопилот PX4/ArduPilot внутри использует **NED**; преобразование делает
  мост симулятор–автопилот, отдельно его считать не нужно.
- Начало координат модели — центр между осями моторов, на нижней плоскости рамы
  (как в CAD-модели конструкторов).

## 2а. Домашняя точка, север и высота (мир test_field)

Задаются в `worlds/test_field.sdf`, элемент `<spherical_coordinates>`.

| Что | Значение |
|---|---|
| Начало мира (0, 0, 0) | 55,7818° с.ш., 37,7108° в.д., высота 150 м (WGS84) |
| Оси мира | ENU: +X — восток, +Y — север, +Z — вверх (`heading_deg` = 0) |
| Земля | z = 0 мира = 150 м над уровнем моря |
| Старт дрона | точка (0, 0), носом на **восток** (yaw = 0 в ENU) |
| Барометр | опорная высота 150 м, давление у земли ≈ 99,5 кПа |

Курс (yaw):
- в Gazebo и ROS 2 (REP 103): ENU, 0 = восток, положительно **против** часовой;
- в PX4 и QGroundControl: NED, 0 = север, положительно **по** часовой;
- перевод: `yaw_PX4 = 90° − yaw_ENU`. На старте PX4 покажет курс 90°.

Высота:
- ROS 2 / Gazebo: z вверх, от земли полигона;
- PX4: z вниз (NED), от домашней точки; `z_NED = −z_ENU`;
- GPS и PX4 «высота AMSL»: 150 м + высота над землёй.

Домашняя точка PX4 ставится там, где дрон заармлен, — при старте с площадки
совпадает с началом мира.

## 5. Автопилот (согласовано с Гаджиевой У., 24 октября)

Реальная конфигурация: Holybro Pixhawk 6C Mini, прошивка **PX4**, настройка через
QGroundControl. Симуляция подключается через **PX4 SITL + Gazebo Harmonic**
(тот же код PX4 работает на компьютере вместо платы).

Как оборудование отображается в симуляции:

| Реальный дрон | В симуляции |
|---|---|
| Pixhawk 6C Mini + PX4 v1.17.0 | PX4 SITL v1.17.0 (та же прошивка) |
| IMU, барометр, магнитометр платы | сенсоры imu, air_pressure, magnetometer в модели |
| GPS Holybro M9N (CAN) | сенсор navsat в модели |
| Лидар (I2C/UART) | сенсор gpu_lidar в модели (23 ноября) |
| Модуль питания (напряжение, ток) | симулятор батареи PX4 (параметры SIM_BAT_*) |
| Приёмник пульта SBUS | джойстик QGroundControl или команды из ROS 2 |
| TELEM2, UART 921600, uXRCE-DDS | uXRCE-DDS по UDP (порт 8888) + MicroXRCEAgent |
| TELEM1, радиомодем SiK 433 МГц | MAVLink по UDP (порт 14550) в QGroundControl |

Режимы Manual/Stabilized, Altitude, Position, Hold, Mission, Return, Land
доступны в SITL без изменений. Failsafe проверяются так:

| Failsafe | Как вызвать в симуляции |
|---|---|
| Потеря связи | закрыть QGroundControl / отключить MAVLink |
| Низкий заряд | параметры SIM_BAT_DRAIN, SIM_BAT_MIN_PCT |
| Потеря GNSS | инъекция отказа: `failure gps off` (нужен SYS_FAILURE_EN=1) |

**Нумерация моторов — стандарт PX4 Quad X** (в CAD-модели был порядок Betaflight,
в нашей модели он исправлен). Моторы на реальном дроне подключаются так же:

| Выход MAIN OUT | Положение | Вращение |
|---|---|---|
| 1 | передний правый | CCW |
| 2 | задний левый | CCW |
| 3 | передний левый | CW |
| 4 | задний правый | CW |
