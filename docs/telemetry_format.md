# Формат телеметрии

Сообщение `uav_interfaces/msg/Telemetry`, тема `/uav/telemetry`, частота 10 Гц (предложение, согласуется с инженером по автопилоту).
Состав полей соответствует разделу «Требования к телеметрии» технического задания.

## Поля

| Поле | Тип | Единицы | Описание |
| --- | --- | --- | --- |
| header | std_msgs/Header | — | метка времени измерения |
| uav_id | string | — | идентификатор БПЛА, например `uav_01` |
| latitude | float64 | градусы | широта, WGS84 |
| longitude | float64 | градусы | долгота, WGS84 |
| altitude_m | float32 | м | высота над точкой взлёта (в PX4: −z локальной позиции) |
| speed_mps | float32 | м/с | скорость |
| roll_deg | float32 | градусы | крен |
| pitch_deg | float32 | градусы | тангаж |
| yaw_deg | float32 | градусы | курс, 0 = север, по часовой стрелке, 0…360 (как в PX4) |
| battery_voltage_v | float32 | В | напряжение аккумулятора |
| battery_percent | int8 | % | заряд 0–100, `-1` если неизвестен |
| link_state | uint8 | — | 0 нет связи, 1 слабая, 2 нормальная (как определяется — ниже) |
| flight_mode | string | — | режим полёта, список ниже |
| mission_status | string | — | `IDLE`, `RUNNING`, `DONE`, `ABORTED` |
| alerts | string[] | — | коды аварийных событий, пустой список = норма |

## Режимы полёта (`flight_mode`)

`STABILIZED` (Manual и Stabilized у мультикоптера PX4 — один режим), `ALTITUDE`, `POSITION`, `HOLD`,
`MISSION`, `RTL`, `LAND`, `TAKEOFF`, `OFFBOARD`, `UNKNOWN` (неизвестный номер режима PX4).
Соответствие номерам PX4 — в [autopilot_interface.md](autopilot_interface.md).
В тестовых CSV (`data/test/`) остались старые значения `MANUAL` и `AUTO`: тестовые данные они не портят,
но настоящий автопилот их не выдаёт.

## Состояние связи (`link_state`)

- `0` — PX4 сообщил о потере пульта или наземной станции (флаги `failsafe_flags`);
- `1` — потери нет, но уровень сигнала ниже порога (по умолчанию 30%): порога в PX4 нет, задаём сами;
- `2` — нормальная.

## Система координат

Широта и долгота — WGS84, градусы. Курс — 0 = север, по часовой стрелке (система NED, как в PX4).
Высота — над точкой взлёта. Для данных из Gazebo (ENU) курс пересчитывается: `yaw_deg = 90° − yaw_ENU`.
Подробнее — в `simulation/docs/conventions.md`, раздел 2а.

## Пороги диагностики

Заряд аккумулятора: предупреждение ниже 15%, серьёзная проблема ниже 7% (значения PX4 по умолчанию,
параметры `battery_warn_percent` и `battery_error_percent` узла `diagnostics_node`).
Предупреждения также выдаются для режимов `RTL`, `LAND` и `UNKNOWN`.

## Коды аварийных событий (предложение)

| Код | Когда возникает |
| --- | --- |
| LINK_WEAK | слабый сигнал связи |
| LINK_LOST | потеря связи с наземной системой |
| SENSOR_FAIL | потеря или недостоверность данных датчика |
| LOW_BATTERY | критический заряд аккумулятора |
| ROUTE_BLOCKED | невозможно продолжить маршрут |
| MISSION_ABORT | аварийное завершение миссии |

## Журнал CSV

Одна строка на сообщение, разделитель запятая, первая строка — заголовки в порядке полей выше.
Время `stamp_iso` в формате ISO 8601 (UTC). Список `alerts` записывается одной ячейкой через точку с запятой.
Пример: `data/test/sample_telemetry.csv` (синтетические данные, не результат реального полёта).
