## Почему так

- **Python для узлов.** Задачи программистов на старте — чтение тестовых данных, запись телеметрии, логи. Скорость выполнения не критична, а Python быстрее в разработке.
- **Dev Container.** На Mac нет Ubuntu, а в команде разные ОС. Контейнер даёт всем одну версию ROS 2.
- **Сообщения в отдельном пакете `uav_interfaces`.** Его используют все узлы; в ROS 2 такие пакеты собираются через `ament_cmake`, даже если узлы на Python.
