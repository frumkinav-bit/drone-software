# Принятые решения

| № | Решение | Статус |
| --- | --- | --- |
| 1 | ROS 2 Jazzy на Ubuntu 24.04 | принято |
| 2 | Основные узлы на Python (rclpy); на C++ при необходимости только `lidar_processor` | принято |
| 3 | Окружение — Dev Container (Docker), одинаковое для Mac и Windows | принято |
| 4 | Симуляция — Gazebo Harmonic, запускается на отдельном Windows-ноутбуке (WSL2) | ожидает подтверждения инженеров по моделированию |
| 5 | Связь с автопилотом: MAVLink (MAVROS) или uXRCE-DDS | ожидает выбора автопилота (срок — 26 октября) |
| 6 | Работа в Git: ветка `main` защищена, изменения через pull request | принято |

## Почему так

- **Python для узлов.** Задачи программистов на старте — чтение тестовых данных, запись телеметрии, логи. Скорость выполнения не критична, а Python быстрее в разработке.
- **Dev Container.** На Mac нет Ubuntu, а в команде разные ОС. Контейнер даёт всем одну версию ROS 2.
- **Сообщения в отдельном пакете `uav_interfaces`.** Его используют все узлы; в ROS 2 такие пакеты собираются через `ament_cmake`, даже если узлы на Python.
